======================================================
Math Master - Release Package Files
======================================================

1. MathMaster-release.apk
   - Final signed Release APK for installation on Android phones.

2. my-upload-key.jks
   - Release signing keystore file (Alias: upload).

3. keystore.properties / keystore_credentials.txt
   - Keystore password and configuration details.

4. my_upload_key_base64.txt
   - Base64-encoded backup of my-upload-key.jks.

5. MathMaster_Release_Files.zip
   - All above files bundled in a single ZIP archive for easy one-click download.
